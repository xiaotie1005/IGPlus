# IGPlus
An image viewer, small and fast

## 简介

IGPlus 是一款 Windows 平台的图片浏览器，主打**超大图片流畅打开**和**海量图片快速浏览**。

## 主要功能

### 浏览体验

- **打开超大图片**：支持 40000×30000 像素级别的超大图片正常打开和缩放
- **底部相册栏**：打开文件夹后，底部显示所有图片的缩略图，点击即可切换
- **快速滚动**：相册栏带滑动条，鼠标滚轮可快速翻页，4000+ 张图片也不卡

### 图片操作

- **缩放**：适应窗口、实际大小、放大、缩小
- **旋转**：向左、向右 90° 旋转
- **翻转**：上下翻转
- **拖动**：放大后按住鼠标拖动查看不同区域
- **锁定缩放**：开启后切换图片时，保持相同的缩放比例和显示位置

### 实用工具

**取色器**

- 点击图片任意位置，获取该点的颜色
- 鼠标移动时，跟随显示当前位置和颜色的悬浮框
- 底部信息栏显示坐标和 RGB、HSV、HSL 等多种颜色值
- 所有数值可直接选中复制

**裁剪**

- 鼠标拖动画出裁剪区域，九宫格样式显示
- 可拖动整个框移动位置，也可拖动手柄调整大小
- 底部信息栏显示裁剪区域的坐标和尺寸
- 支持直接保存或另存为新图片

**测量**

- 在图片上点两个点，显示两点之间的像素距离

### 其他

- **F2 重命名**：浏览图片时按 F2，弹窗修改文件名，确定后立即生效
- **全屏**：点击按钮进入全屏，取消了双击全屏避免误触
- **标题栏信息**：显示当前文件名和缩放比例
- **透明背景**：PNG 等带透明通道的图片，以棋盘格背景显示

## 支持格式

JPG、PNG、BMP、GIF、WebP、TIFF 等常见图片格式。
